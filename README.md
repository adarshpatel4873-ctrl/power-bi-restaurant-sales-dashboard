# Restaurant Sales Analysis Dashboard – Power BI

## Project Overview

This project focuses on analyzing restaurant sales data and creating an interactive dashboard using Microsoft Power BI.

The project uses restaurant order details and menu item data to analyze sales performance and present the results through interactive visualizations.

## Tools & Technologies

- Power BI
- Excel/CSV Data
- Data Analysis
- Data Visualization
- DAX
- Power Query
- Dashboard Design

## Project Workflow

### 1. Data Preparation

- Imported restaurant order details data into Power BI.
- Imported menu items data into Power BI.
- Prepared and transformed the data using Power Query.
- Created relationships between the datasets for analysis.

### 2. Data Analysis

- Analyzed restaurant order and sales data.
- Examined menu items and their contribution to sales.
- Created calculated measures using DAX.
- Analyzed key sales performance metrics.

### 3. Dashboard Development

- Created an interactive restaurant sales dashboard.
- Used Power BI visuals to present sales insights.
- Added KPI cards and interactive filters.
- Designed the dashboard for clear and easy interpretation.

## Dashboard

The dashboard provides an interactive visual analysis of restaurant sales and menu performance using Power BI.
